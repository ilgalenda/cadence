Transcript

A conversation, typeset. The person's question is a soft grey bubble on the right; the answer is plain prose on the field, full measure — the answer is the content, so it is never boxed. Between the two sits the readout: a quiet wrapping row of ticks stating what the machine did — model, elapsed, every tool it ran. There are no "You"/"Owl" bylines: with two voices, the shapes are enough.

Readout ticks

One fact each: a dot in the state's colour, then a mono identifier. The dot is the state; the words are the detail. A running tick is the only thing in a transcript that moves.
