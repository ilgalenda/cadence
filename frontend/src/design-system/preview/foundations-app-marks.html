App marks

An agent is an application, so it is drawn as one: a squircle carrying an open, geometric mark. The tile is a flat wash; the symbol is inlaid — a charcoal face with a saturated edge along one side, lit from top-left, resting on the tile rather than printed on it. Colour names the stage, the mark names the agent, and each stage's hue appears three ways: wash on the tile, charcoal on the face, saturated on the edge.

Every symbol is drawn from what the agent does to the data, never as a picture of the tool — no magnifier for research, no pen for writing, no speaker for signals.

The set has a grammar

Because the marks are abstract they can be made to rhyme, which a set of literal pictures cannot do. Marks in a pair are built the same way and differ on one axis, so they read as related and can never be mistaken for each other.

A rhyme is deliberate; a collision is not. Two marks may share a construction only where the pair is the point and the axis between them is legible.

At working sizes

Lead scoringran 4 min ago

The edge is a fixed 1.2 units in the canvas, so it thins with the mark and never becomes a second outline. At 24px what survives is a warm or cool cast along one side — which is how the stage should register at that size.

On chrome the tile drops out and only the face flips to white. The edge is untouched, so there is no second artwork for dark surfaces — one token changes, not the drawing.

What makes eleven marks one set

Not stroke weight — ink. An early set reused the rail's glyphs at 2.3× and measured 12.7% to 25.9% coverage: half read bold and half read faint. You cannot see a 2× difference in ink one symbol at a time, so the rule is a band and the band is measured.

Shipped: 10.57–10.67% ink, heaviest 1.009× the lightest. Measured on the flat face alone, which is why this grid is drawn without its edge: the edge is a function of the face, so measuring after inlay would let a heavy mark hide behind its own light.

Construction

Always Canvas 32×32, safe area 4 → 28, ink 9.5–12%, at most three elements. Anything finer than the pen is texture at this size.
Always One pen, 2.4 units, round-capped and round-joined, for all eleven. A per-symbol weight is how a set drifts into looking like several hands.
Always Scale and offset are solved by measurement, in two passes: scale about the ink centre until the mark carries the band's coverage, then clamp into the safe area. Where the passes disagree the path changes — Signals ran to 29.6 at full ink, and clamping cost it two points of coverage, so its baseline was shortened and re-solved rather than shipped light.
Always The edge is 1.2 units of the stage's saturated colour, down-right, under one pen width. No gradient and no stacked transparency: the hue arrives as a rim, so the symbol still reads charcoal rather than coloured.
Once Depth was faked before it was earned. The first attempt extruded the symbol in a flat grey wall — a colour the palette does not contain, invented to imitate a shadow. Moving the wall from paint into light fixed it: the edge is a hue the system already owns, which is also why it needs no dark-mode variant.
Never A construction the world already uses for something else. Research once read as a probe piercing a surface — an arrow crossing a rule, which is the download glyph in every product on the user's screen. It measured perfectly and meant the wrong thing. It is now three strata with the probe held at depth, ending in a dot rather than an arrowhead: nothing travels, so nothing is being fetched.
Never A shape whose proportion fights its meaning. An earlier GTM passed every measurement three times and still read as a bar chart beside Call analysis. No measurement catches that class of fault — only laying the set out together does.
