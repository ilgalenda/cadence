Colour

Acme's binding palette, given interface roles. White and charcoal are the primary pair; blue is the active signal; green, amber and gold are the secondaries. The system speaks in sync language — locked, drift, fault — so a colour always states a condition rather than a mood.

One background, measured once

Rebuilt 2026-08-19. The field is plain white everywhere — the translucent rail, sheet and gradient ground are retired. Every figure below is measured against #FFFFFF (or solid --chrome for the on-charcoal set); no ranges, no worst cases.

Colour fields — the featured surfaces

Occasional full-bleed colour moments built from the brand secondaries — a featured card, an insights panel, a hero. Each field names its ink; no other pairing is legal. At most one field per view. A field says "look here"; a signal colour says "this is the condition" — the two never trade jobs.

Charcoal — the authority accent

Charcoal is no longer a frame — it is an accent: the primary pill button, the bulk bar, a toast, a tooltip. Objects, never regions. Set .ds-chrome on such an object and every primitive inside it inverts; there is still no dark variant of any component. If a whole pane is charcoal, it is wrong. Rebuilt 2026-08-19 with the frame doctrine's retirement.

Gold

--gold · #C39A49 → #5D4923

Canonical, promoted knowledge. One meaning only, used sparingly, paired with charcoal — and deliberately kept out of the ground.

Two deliberate positions. The guidelines define no red, and an interface must be able to say something is wrong — so --signal-fault is an extension, tuned to sit beside amber rather than shout over it. And gold is held to a single meaning: canonical knowledge. If gold appears anywhere else in the platform, it has been misused.
