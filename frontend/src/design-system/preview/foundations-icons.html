Icons

The rail draws its destinations rather than typing them. Closed, the glyph is the whole row — there is no label beside it — so the set has one governing rule: identity lives in the outline, not the interior. At 17px with a 1.1 stroke, detail finer than about 3px does not survive. Two icons that share a bounding shape are the same icon, whatever sits inside them.

The rule, and what it cost to learn

The set grew without a card, and nine glyphs collided. Three paths drew one line-of-dots between them, so a third of the Paths group was unreachable without hovering each in turn. Four more shared an identical r=5 outer circle — target, radar, quiz, clock — and read as circle, circle, circle, circle. An envelope carried both Composer and Recap; one hub served both Knowledge and Admin. Each of those is now a distinct silhouette.

Enforced by lib/icons.test.ts: every rail destination resolves, no two share a name, and no two names share a drawing.

On chrome, at rail size

Where they actually live. The glyph is drawn at --chrome-ink / 0.74 — the label's own contrast, not --chrome-ink-muted. When the mark is the only thing in the row it is content, not metadata, and must not sit at the metadata floor.

17px in a 2.25rem square — the collapsed rail. Read down without hovering: every destination should be nameable from its outline alone.

For comparison — 13px at --chrome-ink-muted, which is what the closed rail used to be. Same glyphs, the same 5.83:1 the tokens file calls the floor.

Drawing one

  • Silhouette first. Before the detail, check the outline against every glyph already in the set. If it shares one, the new icon is the one that moves.
  • 14×14 box, 1.1 stroke, currentColor. The mark inherits the row's state — hover, active, chrome — so it must never name a colour of its own.
  • Knock out with even-odd, never with a background colour. A shape painted --chrome is only invisible while the row is inactive; the active row inverts to near-white and the knockout reappears as a blot.
  • One destination, one icon. Reusing a glyph for a second row is the defect this card exists to prevent.
